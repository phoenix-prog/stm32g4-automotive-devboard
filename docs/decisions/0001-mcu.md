# ADR 0001 — MCU: STM32G431CBT6

**Status:** Proposed
**Date:** 2026-09-29

## Context

Rev A needs one CAN FD channel, USB full speed, a Cortex-M4F core, and a package that can be hand-assembled.

The previous attempt (archived as `stm32g4-automotive-devboard-v0`) chose the G431 while advertising dual CAN and a CAN1↔CAN2 bridge. The G431 has one FDCAN, so that scope was not achievable on that part.

## Decision

STM32G431CBT6: Cortex-M4F at 170 MHz, 128 KB flash, 32 KB SRAM, LQFP48, one FDCAN, USB FS device.

## Alternatives considered

| Option | Why not for Rev A |
|---|---|
| STM32G474 / G473 | Three FDCAN. Needed only for multi-bus work, which is out of scope. Higher cost. Revisit if Rev B adds a second bus. |
| STM32G491 | Two FDCAN. Same reasoning. |
| STM32F446 | Familiar, but bxCAN (classic CAN only), no CAN FD. |

## Consequences

- One CAN bus only. No on-board bridge or gateway.
- If a second bus is ever required, the MCU changes. Record that as a new ADR, not an edit to this one.
